    Ways to improve

      A “not found” result means the password was not present in the data currently indexed by Have I Been Pwned. It cannot prove a password has never been exposed.

      Designed to keep the password private

      The password is hashed locally. Only the first five characters of its SHA-1 hash are sent to the Have I Been Pwned range API; the browser compares the returned suffixes. This is a k-anonymity lookup, not a guarantee of zero information leakage.
